The app allows users to search for any city and get real-time weather information including temperature, humidity, weather conditions, and wind speed.

 Features

- Search weather by city name
- Real-time weather data using OpenWeatherMap API
- Clean and responsive UI
- Backend built with Express.js
- MongoDB database integration
- Error handling for invalid city names
- Environment variable security using `.env`

Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### API
- OpenWeatherMap API
